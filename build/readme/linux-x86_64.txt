Tinkerie {VERSION} for Linux on a 64-bit Intel or AMD PC
Free maker tools, designed and created by nrmluvdev.
This is an ALPHA version: it works, but it is still being tested, so expect rough edges.
Free software under the GNU GPL, version 3 or later (see source/LICENSE). No warranty.
Source and updates: https://github.com/normanlove/tinkerie

Starting Tinkerie
    ./tinkerie
To add it to your applications menu:  ./install.sh   (remove again with ./install.sh --remove)
Tinkerie's windows open in Chromium, Chrome, Edge or Brave if you have one, otherwise in your
default browser. For USB serial devices (like printers for Tunie), your user needs to be in the
dialout group:  sudo usermod -aG dialout $USER   then log out and back in.

What works on this system
- Launcher, Wirie, Makie, Tunie and Flashie: everything.
- Scopie: everything, including USB scopes like the Hantek 6022BE. Run ./install-usb.sh once first
  (it asks for your password), then unplug and replug the scope.
- Tracie: the serial monitor, and USB logic analysers after ./install-usb.sh.
- Meterie: meters with a USB-serial cable, like the HoldPeak HP-90EPC. Meters with a HID USB
  cable, Bluetooth meters and Camera mode are Windows only for now.
Every app has teaching mode: point at anything to see what it does. F2 turns it off.

New in {VERSION}:
- Tinkerie is now marked as alpha while it is tested on real hardware.
- Wirie: the auto-router now draws ground (GND) tracks too, so every connection is
  visible, and it checks the ground fill really reaches each pin.

New in 1.5.1: every app opens maximised.

New in 1.5.0: Flashie's "Write image" tab can now
- set up Raspberry Pi OS before its first start, like Raspberry Pi Imager: press "OS settings"
  for the hostname, your username and password, Wi-Fi, SSH and time zone/keyboard;
- turn a Windows 10 or 11 .iso into a USB installer for UEFI PCs, like Rufus;
- write Linux ISOs (Ubuntu, Fedora, Mint...) and .zst-packed images too.
These new parts haven't been tried on real hardware yet. Please report anything odd.

Updating
The full source is in the source folder. Change anything, then in a terminal:
    cd source
    ./build.sh linux
The new build appears in source/dist/linux-x86_64. You need Go 1.24 or newer (https://go.dev/dl/).
source/README.md explains the suite; source/PORTING.md explains the layout and what's left to port.
