Tinkerie {VERSION} for Windows 10 or 11 (64-bit)
Free maker tools, designed and created by nrmluvdev.
This is an ALPHA version: it works, but it is still being tested, so expect rough edges.
Free software under the GNU GPL, version 3 or later (see source/LICENSE). No warranty.
Source and updates: https://github.com/normanlove/tinkerie

Starting Tinkerie
Double-click Tinkerie.exe. It needs nothing installed.

What works on this system
Everything, in every app. Every app has teaching mode: point at anything to see what it does.
F2 turns it off.

New in {VERSION}:
- New version numbers: Tinkerie and every app are now numbered below 1.0 while
  in alpha.
- Flashie: ESP32 Marauder and Bruce were removed from the firmware library.

Also in recent alpha builds:
- Wirie's auto-router draws ground (GND) tracks too, and checks the ground fill
  really reaches each pin.
- Every app opens maximised.
- Flashie's "Write image" tab sets up Raspberry Pi OS before its first start
  (OS settings: hostname, user, Wi-Fi, SSH, time zone), turns a Windows 10/11
  .iso into a USB installer for UEFI PCs, and writes Linux ISOs and .zst images.
  These haven't been tried on much real hardware yet. Please report anything odd.

Updating
The full source is in the source folder. Change anything, then run build.bat in it.
You need Go 1.24 or newer (https://go.dev/dl/).
