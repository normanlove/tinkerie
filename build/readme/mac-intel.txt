Starting Tinkerie
1. Drag Tinkerie.app into your Applications folder.
2. The first time, macOS blocks it because it isn't from the App Store: open it once, then go to
   System Settings > Privacy & Security and click "Open Anyway". (Or in Terminal:
   xattr -dr com.apple.quarantine /Applications/Tinkerie.app)
3. Tinkerie's windows open in Chrome, Edge or Brave if you have one, otherwise in your default browser.

What works on this system
- Launcher, Wirie, Makie, Tunie and Flashie: everything.
- Scopie: demo, network and bench scopes, and CSV files. USB scopes aren't available on Mac yet.
- Probie: the serial monitor. The USB logic analyser isn't available on Mac yet.
- Codie: everything.
- Meterie: meters with a USB-serial cable, like the HoldPeak HP-90EPC. Meters with a HID USB
  cable, Bluetooth meters and Camera mode are Windows only for now.
Every app has teaching mode: point at anything to see what it does. F2 turns it off.

New in {VERSION}:
- Keebie: a Parts view shows every diode, LED and capacitor before you build
  (they go on the back of the board); choose how the diodes are laid out
  (beside, below, above or at 45 degrees, back or front) and add a capacitor
  beside each LED.
- Keebie: drag and turn the controller, and lay its parts out packed, in rows
  or in one line.
- Keebie: New keyboard and Close keyboard buttons.

Also in recent alpha builds:
- 0.11.0-alpha: Tracie became Probie, with an Explain tab; Codie is code only.
- 0.10.0-alpha: Codie explained signals (now Probie's Explain tab).
- 0.9.1-alpha: Keebie fixes (key spacing, widening keys, faster redraws).
- 0.9.0-alpha: Flashie keyboard firmware, Makie keyboard cases, Keebie knobs
  and screens, version numbers in every download's name.
- 0.8.0-alpha: Keebie, custom keyboard PCB designer, in Wirie.
- 0.7.0-alpha: new app Codie, the code explainer, with Game logic and Game school.
- 0.6.1: the version in the Windows file details matches the alpha numbering.
- Tinkerie and every app are numbered below 1.0 while in alpha (0.6.0).
- Flashie: ESP32 Marauder and Bruce were removed from the firmware library.
- Wirie's auto-router draws ground (GND) tracks too, and checks the ground fill
  really reaches each pin.
- Every app opens maximised.
- Flashie's "Write image" tab sets up Raspberry Pi OS before its first start
  (OS settings: hostname, user, Wi-Fi, SSH, time zone), turns a Windows 10/11
  .iso into a USB installer for UEFI PCs, and writes Linux ISOs and .zst images.
  These haven't been tried on much real hardware yet. Please report anything odd.

Updating
The full source is in the source folder. Change anything, then in a terminal:
    cd source
    ./build.sh mac-intel
The new build appears in source/dist/mac-intel. You need Go 1.24 or newer (https://go.dev/dl/).
source/README.md explains the suite; source/PORTING.md explains the layout and what's left to port.
