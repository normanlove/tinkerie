Free maker tools by **nrmluvdev**: Wirie, Makie, Tunie, Flashie, Scopie, Meterie and Tracie in one program.

### Which file?
- **Windows 10/11:** `Tinkerie.exe` (just run it), or `Tinkerie-{VERSION}-windows.zip` if your connection blocks .exe downloads (it also has the source)
- **Mac:** `…-mac-apple-silicon.zip` (M1 or newer) or `…-mac-intel.zip`
- **Linux PC:** `…-linux-x86_64.tar.gz`
- **Raspberry Pi:** `…-pi-64bit.tar.gz` (64-bit Raspberry Pi OS) or `…-pi-32bit.tar.gz`

Each package has a *READ ME FIRST.txt*.

### New in {VERSION}
- Every app opens maximised.

### New in 1.5.0 — Flashie's Write image tab
- **OS settings** like Raspberry Pi Imager: hostname, username and password, Wi-Fi, SSH and time zone/keyboard, set before the first start (cloud-init for Raspberry Pi OS Trixie and Ubuntu, firstrun.sh for older Raspberry Pi OS).
- **Windows 10/11 installer USB drives** from a Windows .iso, for UEFI PCs (FAT32, or FAT32 + exFAT when install.wim is over 4 GB).
- **Linux ISOs** and **.zst** images.

⚠️ These new Write image features haven't been tested on real hardware yet. Please [report](https://github.com/normanlove/tinkerie/issues) anything that doesn't work.
