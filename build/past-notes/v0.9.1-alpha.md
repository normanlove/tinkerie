> ⚠️ **Tinkerie is in alpha.** Everything works, but it's still being tested on real hardware, so expect rough edges and changes. Please [report](https://github.com/normanlove/tinkerie/issues) anything that doesn't work.

Free maker tools by **nrmluvdev**: Wirie, Makie, Tunie, Flashie, Scopie, Meterie, Tracie and Codie in one program.

### Which file?
- **Windows 10/11:** `Tinkerie-0.9.1-alpha-windows.exe` (just run it), or `Tinkerie-0.9.1-alpha-windows.zip` if your connection blocks .exe downloads (it also has the source)
- **Mac:** `…-mac-apple-silicon.zip` (M1 or newer) or `…-mac-intel.zip`
- **Linux PC:** `…-linux-x86_64.tar.gz`
- **Raspberry Pi:** `…-pi-64bit.tar.gz` (64-bit Raspberry Pi OS) or `…-pi-32bit.tar.gz`

Each package has a *READ ME FIRST.txt*.

### New in 0.9.1-alpha
Keebie fixes:
- **Key spacing no longer wipes out the layout.** The field now shows the real spacing (19.05 mm for MX) and only accepts 15–25 mm; before, one click on its arrow set 1 mm and squashed every key into a dot.
- **Changing a key's width pushes the keys beside it along** instead of overlapping them, on staggered and column-staggered layouts.
- **Much faster redraws**, especially on angled layouts like the Alice (about 2.4 s down to 0.2 s per change). Rounded outlines now use far fewer points.
- Very large X or Y values no longer make the board disappear; building with no keys explains what to do.
