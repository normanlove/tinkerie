> ⚠️ **Tinkerie is in alpha.** Everything works, but it's still being tested on real hardware, so expect rough edges and changes. Please [report](https://github.com/normanlove/tinkerie/issues) anything that doesn't work.

Free maker tools by **nrmluvdev**: Wirie, Makie, Tunie, Flashie, Scopie, Meterie, Probie and Codie in one program.

### Which file?
- **Windows 10/11:** `Tinkerie-0.20.0-alpha-windows.exe` (just run it), or `Tinkerie-0.20.0-alpha-windows.zip` if your connection blocks .exe downloads (it also has the source)
- **Mac:** `…-mac-apple-silicon.zip` (M1 or newer) or `…-mac-intel.zip`
- **Linux PC:** `…-linux-x86_64.tar.gz`
- **Raspberry Pi:** `…-pi-64bit.tar.gz` (64-bit Raspberry Pi OS) or `…-pi-32bit.tar.gz`

Each package has a *READ ME FIRST.txt*.

### New in 0.20.0-alpha
- **Apps open in front of the launcher:** on Windows, every app's window now comes to the front when you start it from the launcher, instead of opening behind it (Windows normally stops background programs from doing that). Meterie's own window does the same.
- **Linux and Raspberry Pi OS:** the new window is brought forward too when wmctrl or xdotool is installed (X11 desktops); on a Mac it already was.
