Code signing policy

Code signing policy

How Tinkerie's Windows program is signed, who decides what gets signed, and what Tinkerie does (and doesn't do) with your data.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signing is being set up. Releases made before it's in place are not signed, and Windows shows an "unrecognised app" warning for them.

What is signed

The Windows program, Tinkerie.exe (released as Tinkerie-<version>-windows.exe), attached to each GitHub release, on its own and inside the Windows zip. It is built from this project's source code by GitHub Actions, on GitHub's own servers, using the public release workflow. Nothing built anywhere else is signed.

Signing proves the file came from this project's source code and hasn't been changed since. The Mac and Linux downloads are not part of this signing.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Tinkerie has no analytics, no tracking, no accounts and no automatic update checks.

These are the only times it uses the network, each one because you asked:

  • Flashie downloads firmware, the Arduino board list and Raspberry Pi's OS list from those projects' own servers (GitHub, Raspberry Pi, MicroPython, CircuitPython and the others shown in its library) when you open its library or choose something to download.
  • Tunie talks to your own printer (OctoPrint or Moonraker) only at the address you type in.
  • Scopie connects to a network oscilloscope only at the address you choose.
  • Everything else Wirie, Makie, Meterie, Probie, Codie, Fixie and the launcher never use the internet. Each app's page is served only to your own computer (localhost).

Those sites have their own privacy policies. This website is hosted by GitHub Pages and loads its fonts from Google Fonts.

Changes to your computer

Tinkerie doesn't need installing: delete it to remove it. Two optional steps change your system, and both ask first: on Windows, Scopie's Install USB driver button runs Zadig to install a USB driver (you'll see the administrator prompt; Probie's help explains the same step for logic analysers), and on Linux and Raspberry Pi, install.sh and install-usb.sh add a menu entry and USB permissions. Both scripts undo themselves with --remove. The Windows driver can be removed in Device Manager.
