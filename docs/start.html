Getting started

Up and running in five minutes

Download, open, pick an app. Here's exactly what to do on your computer, and a good first thing to try in each app.

Step by step

Install on your computer

  1. Download Tinkerie for Windows

    Tinkerie-0.10.0-alpha-windows.exe, from the download list. If your network blocks .exe files, take the Windows zip and unzip it.

  2. Double-click it

    Windows may say it's an unrecognised app, because it isn't signed with a paid certificate. Click More info, then Run anyway.

  3. Pick an app

    The launcher opens. Click an app, or press its number key (1–7).

  4. Optional: pin it

    Right-click Tinkerie.exe and choose Pin to Start or Pin to taskbar.

  1. Download the right zip

    Apple silicon (M1 or newer) or Intel. Check under › About This Mac if you're not sure.

  2. Move it to Applications

    Unzip it and drag Tinkerie.app into your Applications folder.

  3. Allow it once

    The first time, macOS blocks it. Open it once, then go to System Settings › Privacy & Security and click Open Anyway.

  4. Pick an app

    The launcher opens in Chrome, Edge or Brave if you have one, otherwise in your normal browser.

  1. Download and unpack

    Get the Linux .tar.gz and unpack it.

  2. Start it

    cd Tinkerie-*-linux-x86_64
./tinkerie

  3. Add it to your menu

    ./install.sh
    Remove it again with ./install.sh --remove.

  4. For USB devices

    For serial boards, join the dialout group: 

    sudo usermod -aG dialout $USER
    For USB scopes and logic analysers, run ./install-usb.sh once. Then log out and back in.

  1. Pick 64-bit or 32-bit

    Most Raspberry Pi OS installs are 64-bit now. Type uname -m in a terminal: aarch64 means 64-bit.

  2. Download and unpack

    tar xzf Tinkerie-*-pi-64bit.tar.gz
cd Tinkerie-*-pi-64bit

  3. Start it and add it to the menu

    ./tinkerie
./install.sh

  4. For USB devices

    sudo usermod -aG dialout $USER
./install-usb.sh
    Then log out and back in.

Learning as you go

Teaching mode

Every app starts with teaching mode switched on. Rest the mouse on any button, setting or panel and a card appears explaining what it does and when you'd use it.

Once you know your way around, press F2 to turn the cards off. Press it again any time to bring them back. Each app remembers your choice.

Scopie keeps its explanations in a help bar under the scope screen, and has a beginner's guide on F1.

First things to try

One easy win in each app

None of these needs any hardware.

Wirie

On the welcome screen, click Example project: a Pico weather station with a screen, sensor, button and LED.

Makie

Click Show me an example on the welcome screen. Makie builds a hand-cranked 9:1 gearbox.

Tunie

Choose it from 40 presets (Creality, Prusa, Bambu Lab, Voron…) and pick your filament.

Flashie

Use a USB cable that carries data. Flashie lists it and guesses what it is.

Scopie

No scope needed: pick a practice signal like the probe calibration square.

Meterie

Plug in its USB cable, switch the meter's PC link on, then open Meters and press Scan.

Tracie

Pick DEMO in the port list and press Connect. No hardware needed.

Codie

The Examples menu has everyday programs, Windows Go, game engines and 1980s BASIC.

Handy to know

Tips

Start an app directly

Make a desktop shortcut to Tinkerie.exe --app makie, or rename a copy of Tinkerie.exe to Makie.exe. On Linux and Mac, a link called makie does the same.

Run several at once

Each app opens in its own window and keeps running after you close the launcher, so you can have Flashie and Tracie open side by side.

Your work is saved

Wirie and Makie save as you go and pick up where you left off next time.
