About Tinkerie

A few words from nrmluvdev on where these tools came from, the part AI played in building them, and why they'll always be free.

Why it exists

Tinkerie is the set of tools I wish I'd had at every stage of my journey into engineering, microelectronics and making in general. Designing a circuit board, printing a case for it, flashing its firmware, measuring what it's doing, working out what a piece of code actually does: each step used to mean another program, another account, another manual.

So I've tried to make those tools exist, in one place, for everyone else who could benefit from them.

My view on AI

I believe AI is useful as a tool in the same way a saw is useful for cutting wood. It does the job it was designed for well, but it doesn't create things by itself. A saw doesn't decide what the table looks like.

AI is a language model, so it should be used to translate the ideas in your head into tangible things, not to come up with the ideas themselves.

I don't agree with how AI is being implemented in much of the world today. It should be used to improve our environment, not at its cost.

How Tinkerie is made

Tinkerie is built mostly by AI, but the core ideas behind it are entirely mine: which tools should exist, what each one is for, what it should feel like to use, and who it's meant to help. The AI writes much of the code that turns those ideas into working software. I decide what gets built, test it, and choose what ships.

All of the source code is public on GitHub, so anyone can see exactly how every tool works.

Free, forever

Every Tinkerie tool is, and always will be, completely free. No paid tiers, no locked features, no accounts, no adverts.

I'll only ever ask for donations if the project grows to a point where it needs them to keep going, and even then, donating will never be required to use anything. Tinkerie is free software under the GNU General Public License, version 3 or later, so it stays free for everyone to use, study, share and improve.

— nrmluvdev
