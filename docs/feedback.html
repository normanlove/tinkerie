Report a bug or ask for a feature

Fill this in and press the button: it opens a ready-made report on GitHub, where nrmluvdev reads every one and you can follow what happens to it. You'll need a free GitHub account to post it.

What is it?

Screenshots, logs and saved files can be dragged into the report on GitHub before you post it. Please leave out passwords, Wi-Fi details and anything private: reports are public.
